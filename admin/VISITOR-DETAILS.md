# CM Infinia visitor details

Follow [ADMIN-SETUP.md](../ADMIN-SETUP.md) for setup in the dedicated CM Infinia Supabase project.

Open admin.html and select Visitor Details. Search registered and anonymous visitors, inspect sessions and page journeys, and delete a single visitor or all visitor analytics. Registration records in Visitors are managed separately.

The tracker records SubPages browsing, including the seven 3BHK/360 rooms. It links anonymous and registered activity within a tab. The first room is visible without registration; changing rooms prompts for details.

IP geolocation is disabled by default. Empty IP/location values do not imply a failed browsing session.
